## メイン投稿案

画面録画のMP4を投げると、完全ローカルで「作業ログ」が出てくるツールをOSSにしました。

- 画面の文字（OCR）＋何をしてたか（VLM）＋喋ってたこと（ASR）を1本のタイムラインに統合
- `00:05:00〜00:12:30（7分30秒）— Excel — 見積書.xlsx` みたいな見出しで滞留時間つき
- アプリ別の滞在時間も自動集計（稼働報告の下資料になる）
- クラウドに一切送らない。会議録画・機密画面もOK
- Mac（Apple Silicon）/ Windows 対応、Apache-2.0

Claude Codeユーザーはskillを入れると「この録画ログにして」で動きます。

## リプライ連投案（スレッド）

1. なぜ作ったか: 録画を見返して日報を書くのが苦痛だった。OCRだけだと「何をしてたか」が、音声だけだと「画面で何が起きたか」が分からない。両方を突き合わせるツールが世界に存在しなかった（3回市場調査して空白を確認）

2. 技術スタック: PaddleOCR（日本語CPU）＋ Qwen3-VL 8B（Ollama）＋ kotoba-whisper v2（Mac:MLX / Win:faster-whisper自動切替）。VLMの無駄撃ちをOCRトークンのJaccard類似度でゲートするのが工夫どころ

3. 品質へのこだわり: Whisperの無音幻覚「!」を統計フィルタで除去、VLMの幻覚ファイル名を品質ゲートで棄却、一次情報（生OCR）は必ず保持して後から再解釈可能に。テスト200件超、CI はubuntu+windows

4. 用途: 会議録画の議事メモ / 作業の振り返り / SES稼働報告の下資料 / 「あのファイルどこで触ったっけ」の検索（RAG化は開発中）
